# toc v0.2.1 변환 확장과 TUI 계약 설계

**작성일:** 2026-08-08  
**상태:** 사용자 승인·구현 진행  
**대상:** `toc` CLI와 `toc tui`  
**제품 요구사항:** `docs/prd/v0.2.1-prd.md`

## 1. 설계 결정

| 항목 | 결정 |
|---|---|
| 변환 공개면 | 기존 단일 정적 레지스트리의 정확히 24개 고정 ID |
| 실행 경계 | 공개 Pipeline은 `StrictText`, CLI 내부만 최소 `AllowBinary` 래퍼 |
| TUI Final | Pipeline `f`·`ㄹ`이 기존 `restore_final` 경로 재사용 |
| Output Final | `f`·`ㄹ` 무동작, Dock·Help 미표시 |
| Output 제목 | `» OUTPUT [VIEW] [N B]`, 조건 불충족 시 크기 대괄호 전체 생략 |
| 새 의존성 | `data-encoding 2.11.1`, `html-escape 0.2.15`, `sha2 0.11.0`, 순수 Rust 백엔드의 `flate2 1.1.9` |

새 키맵 자료형, Recipe, 범주, 옵션, Artifact 유형화, 새 View는 만들지 않는다. 기존
`state.rs`의 실제 키 분기와 `render.rs`의 Dock·Help·제목 경계에서만 TUI 계약을 바꾼다.

## 2. 변환 구성과 경계

새 변환은 작은 내부 모듈로 두고 `src/transforms/mod.rs`에서 선언한다. 공개 등록은 마지막
통합 단계에서 한 번만 수행한다. 이 순서는 개별 변환 구현이 CLI·Picker에 반쯤 노출되는 것을
막는다.

| 그룹 | 내부 동작 | 주요 경계 |
|---|---|---|
| 인코딩 | Base64URL, Base32, HTML, ROT13 | 정규 인코딩과 제한된 ASCII 공백만 허용 |
| IOC | URL Defang·Refang | 정확한 소문자 토큰만 상호 변환 |
| 토큰 | JWT Decode | 세 JWS 부분, 엄격 JSON 객체, Signature 미검증 표시 |
| 바이트 | SHA-2, Gzip | 결정적 Gzip 헤더, 전 멤버·CRC·후행 쓰레기 확인 |
| 줄 | Sort, Deduplicate | LF 정규화, 끝 줄바꿈 보존, 백만 줄 상한 |

Base64URL과 Base32 디코딩은 정규 후행 비트를 검사한다. HTML Decode는 유효하고 세미콜론이
완전한 엔터티 외에는 바꾸지 않는다. JWT 출력은 Header, Payload, Signature, Warning 순서로
두 칸 들여쓴 JSON이며 Warning 값은 `Signature not verified`다.

모든 가변 길이 결과는 할당 전 검사된 길이를 계산하거나 쓰기 중 한도를 확인한다. Gzip과
JWT 조합을 포함해 오류 시 부분 Artifact를 반환하지 않는다. 오류 렌더링은 입력 원문·토큰·
전체 이진 결과를 노출하지 않는 기존 안전 경계를 따른다.

## 3. TUI 동작 상세

`restore_final`은 보관 Artifact·Trace를 활성 결과로 복사하고, 요청 ID와 스크롤 오프셋을
기존 방식으로 갱신한다. Pipeline `f`·`ㄹ`은 이 경로만 호출한다. Output에서는 해당 두 키를
매치하지 않아 복원, 상태 메시지, 요청 생성 어느 것도 일어나지 않는다.

Pipeline Dock과 전체·작은 Help에는 `f Final`을 넣고 한글 별칭은 표시하지 않는다. Output의
Dock·Help에서는 Final 항목을 제거한다. 공간 부족 Dock은 기존 완전 명령 그룹 생략 규칙을
계속 사용한다.

제목은 먼저 `» OUTPUT [VIEW]` 또는 `» OUTPUT / STEP NN [VIEW]`를 만든다. Ready와
Artifact 조건을 모두 만족하면 뒤에 하나의 ` [N B]` 접미사를 만들고, 테두리를 포함한
가용 폭에 모두 맞을 때만 사용한다. 이전 ` · N B`, 위치 카운터, 상태 중 이전 결과 크기
표시는 사용하지 않는다.

## 4. 검증 계획

- 상태 단위시험: Pipeline `f`·`ㄹ` 복원, Output `f`·`ㄹ` 무동작, 기존 취소·Trace·복사 회귀
- 렌더 단위시험: Final의 Dock·전체 Help·작은 Help 위치, 제목의 최종·단계·폭 부족·비 Ready
- 변환 단위시험: RFC 벡터, 비정규 입력, 경계 길이, 오류 시 부분 결과 부재
- 통합시험: 24개 목록·도움말·`--then`·Picker·Trace, 파이프 이진 성공과 실제 터미널 거부
- 릴리스 검증: 형식, 경고 금지 Clippy, 전체 시험·rustdoc, PTY와 가능한 macOS Pasteboard

X11·Wayland는 실행 가능한 세션이 없으면 미검증으로 기록한다. 검증 결과는 역사 문서가
아닌 README와 이 v0.2.1 설계 문서에만 갱신한다.
