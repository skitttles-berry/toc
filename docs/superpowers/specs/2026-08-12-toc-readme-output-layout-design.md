## CLI 사용법

CLI 예제는 `console` 코드 블록 하나로 표시한다. 실행 가능한 명령 앞에는 `$`를 붙이고,
결과가 있는 예제는 명령 바로 다음 줄에 실제 출력을 둔다.

- Base64 예제 다음 줄에 `aGVsbG8=`을 표시한다.
- URL Decode와 JSON 정리 예제 다음 줄에 정리된 JSON을 표시한다.
- 입력 파일과 Binary 리디렉션 예제는 결과가 파일 내용이나 파일 자체이므로 명령만
  표시한다.
- 코드 블록과 같은 결과를 되풀이하는 설명 문단은 삭제한다.
- 표준 입력, `--input PATH`, 끝 줄바꿈, Binary 리디렉션 안내는 유지한다.

## TUI 사용법

상단의 `TUI 실행 화면` 섹션을 없애고, 기존 녹화 링크를 `TUI 사용법` 도입부 바로 뒤의
`### 실행 화면`으로 옮긴다. 녹화 클릭 안내 문장은 삭제하고 SVG 미리보기 링크만 둔다.

기존 `### 화면 구성` 제목, 설명, ASCII 화면, 터미널 크기 안내는 모두 삭제한다. 이어지는
4단계 시작, Output View, 단축키와 Raw Copy 호환성 안내는 유지한다.
