# doop v0.2 Hex Transform Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 승인된 v0.2 요구사항에 따라 기존 공용 레지스트리와 파이프라인에 `hex-encode`, `hex-decode`를 추가하고 CLI와 TUI에서 동일하게 제공한다.

**Architecture:** `src/transforms/hex.rs`에 두 순수 변환 함수를 두고 기존 `TransformFn` 서명과 `TransformDefinition` 정적 목록에 직접 연결한다. 오류 형식, UTF-8 불변식, CLI 원자적 출력, TUI 미리보기 실행은 기존 오류 모형과 공용 파이프라인을 그대로 재사용하며 CLI와 TUI 전용 구현은 만들지 않는다.

**Tech Stack:** Rust 1.97.1, Rust 2024 Edition, 표준 라이브러리, 기존 정적 변환 레지스트리와 파이프라인, Cargo 기본 시험, 기존 Expect 기반 Bash/Zsh 점검

## Global Constraints

- 제품명, Cargo 패키지명, 실행 파일명은 모두 `doop`이며 릴리스 버전은 `0.2.0`이다.
- Rust `1.97.1`, Rust 2024 Edition, 단일 Cargo 패키지와 단일 실행 파일 구조를 유지한다.
- 사용자가 지정한 `main` 브랜치에서 구현하며 GitHub Actions, PR, 푸시는 만들지 않는다.
- 제품 도움말·오류·TUI 문구는 영어, 저장소 문서는 한국어로 작성한다.
- 공개 변환 ID 집합은 `base64-encode`, `base64-decode`, `url-encode`, `url-decode`, `format-json`, `minify-json`, `hex-encode`, `hex-decode` 정확히 8개이며 각 ID는 한 번만 등록하고 `tui`와 충돌하지 않는다.
- 공개 목록 순서를 호환성 규약으로 만들지 않으며 시험은 순서가 아닌 집합과 중복 부재를 검증한다.
- `hex-encode`는 임의 바이트를 바이트당 두 개의 소문자 ASCII 16진수로 바꾸며 접두사, 구분자, 공백, 그룹화, 끝 줄바꿈을 추가하지 않는다.
- `hex-decode`는 ASCII space (`0x20`), tab (`0x09`), CR (`0x0d`), LF (`0x0a`)만 무시하고 대소문자 ASCII 16진수만 허용한다.
- 허용되지 않는 바이트는 원본 0 기반 오프셋의 `invalid hex character at byte {position}`, 홀수 숫자 수는 `hex input has an odd number of digits: {digits}`로 표시한다.
- 디코딩 성공 결과는 유효한 UTF-8이어야 한다. 실패 시 기존 최대 64바이트 소문자 16진수 미리보기와 전체 바이트 수를 사용하고 손실 치환이나 원시 바이트 성공 결과를 제공하지 않는다.
- 인코딩은 `input.len().checked_mul(2)`, 디코딩은 검사된 숫자 수와 `digits / 2`로 결과 길이를 먼저 구하고 출력 한도 확인 뒤에만 할당한다.
- CLI 입력 한도는 64 MiB, CLI 단계 출력 한도는 256 MiB, TUI 입력 한도는 1 MiB, TUI 단계 출력 한도는 64 MiB, 최대 단계 수는 32개다.
- 새 16진수 의존성, trait, 팩터리, 자동 등록 매크로, 플러그인 계층, 별도 크레이트를 추가하지 않는다.
- 기존 v0.1 PRD는 역사적 기준이므로 여섯 변환이라는 v0.1 문구를 v0.2 값으로 고치지 않는다. v0.2 변경은 v0.2 PRD, 설계, README에만 반영한다.

`src/transforms/hex.rs`의 시험 앞에 다음 구현을 추가한다.

```rust
use crate::error::{TransformError, hex_preview};

const HEX: &[u8; 16] = b"0123456789abcdef";

fn hex_value(byte: u8) -> Option<u8> {
    match byte {
        b'0'..=b'9' => Some(byte - b'0'),
        b'a'..=b'f' => Some(byte - b'a' + 10),
        b'A'..=b'F' => Some(byte - b'A' + 10),
        _ => None,
    }
}

fn is_ignored(byte: u8) -> bool {
    matches!(byte, b' ' | b'\t' | b'\r' | b'\n')
}

pub fn encode(input: &[u8], output_limit: usize) -> Result<Vec<u8>, TransformError> {
    let required = input
        .len()
        .checked_mul(2)
        .ok_or(TransformError::OutputTooLarge {
            limit: output_limit,
        })?;
    if required > output_limit {
        return Err(TransformError::OutputTooLarge {
            limit: output_limit,
        });
    }

    let mut output = Vec::with_capacity(required);
    for &byte in input {
        output.push(HEX[(byte >> 4) as usize]);
        output.push(HEX[(byte & 0x0f) as usize]);
    }
    Ok(output)
}

pub fn decode(input: &[u8], output_limit: usize) -> Result<Vec<u8>, TransformError> {
    std::str::from_utf8(input).map_err(|_| TransformError::InvalidUtf8Input)?;

    let mut digits = 0usize;
    for (position, byte) in input.iter().copied().enumerate() {
        if is_ignored(byte) {
            continue;
        }
        if hex_value(byte).is_none() {
            return Err(TransformError::InvalidHex { position });
        }
        digits = digits
            .checked_add(1)
            .ok_or(TransformError::OutputTooLarge {
                limit: output_limit,
            })?;
    }

    if !digits.is_multiple_of(2) {
        return Err(TransformError::OddHexDigitCount { digits });
    }
    let required = digits / 2;
    if required > output_limit {
        return Err(TransformError::OutputTooLarge {
            limit: output_limit,
        });
    }

    let mut output = Vec::with_capacity(required);
    let mut high = None;
    for byte in input.iter().copied() {
        if is_ignored(byte) {
            continue;
        }
        let value = hex_value(byte).expect("first pass validated every hex digit");
        if let Some(high) = high.take() {
            output.push((high << 4) | value);
        } else {
            high = Some(value);
        }
    }
    debug_assert!(high.is_none());
    debug_assert_eq!(output.len(), required);

    if std::str::from_utf8(&output).is_err() {
        return Err(TransformError::InvalidUtf8Output {
            preview_hex: hex_preview(&output),
            total_bytes: output.len(),
        });
    }
    Ok(output)
}
```
